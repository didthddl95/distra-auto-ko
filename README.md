# distra-auto-ko

## Auto Korean Translate v0.1.1

Distra용 한국어 자동 번역 실험판.

### 설치
Distra → Plugins → Install from URL:

```text
https://raw.githubusercontent.com/didthddl95/distra-auto-ko/main/
```

기존 설치본을 비활성화하고 제거한 다음 설치하세요. 외부 번역 전송 동의를 켜고 번역 연결 테스트를 실행한 뒤, 번역할 서버 채널 ID를 저장하세요. DM은 제외합니다.

### 주의
선택한 채널의 메시지 텍스트가 Google의 비공식 번역 엔드포인트로 전송됩니다. 민감한 채널은 등록하지 마세요. HTTP 403/429가 발생하면 요청을 중지하세요. Discord 비공식 클라이언트 사용에 따른 계정 위험이 있습니다.

JavaScript 문법 검사 및 모의 번역 테스트는 통과했으나, 실제 iPhone에서의 설치와 번역 연결은 미검증입니다.
